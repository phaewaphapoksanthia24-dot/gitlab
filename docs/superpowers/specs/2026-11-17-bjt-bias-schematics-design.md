# Bias Schematics for All Three Modes — Design

วันที่: 2026-11-17
รายวิชา: ENG29 2121
สถานะ: อนุมัติแล้ว (แนวทาง A)

## ทำไมทำ (intent)

หลังเพิ่มโหมด Fixed และ Emitter ใน Lab 03 หน้าเว็บแสดง schematic เฉพาะโหมด
Voltage Divider ส่วนอีกสองโหมดเหลือเพียงข้อความสั้น ๆ ทำให้ผู้ใช้ไม่เห็นวงจร
ของโหมดที่กำลังคำนวณ ต้องให้ทุกโหมดมีรูปวงจรของตัวเองเหมือนของเดิม

## เป้าหมาย

1. โหมด `divider`, `fixed`, `emitter` แสดง schematic ของตัวเองทุกโหมด
2. ภาพใช้ภาษาภาพเดิม (wire / resistor / transistor / ground / label) และแสดงค่าที่กรอก
3. ไม่ใช้ JavaScript และไม่เพิ่ม dependency

## สิ่งที่ไม่ทำ (non-goals)

- ไม่ทำ circuit editor หรือคำนวณตำแหน่งอัตโนมัติ
- ไม่เปลี่ยนสูตรหรือผลลัพธ์ใด ๆ
- ไม่แตะ `bias.py`, tests, `electrical.py`

## anti-goals

- Fixed/Emitter แสดงรูป divider (วงจรผิด)
- ค่าที่แสดงบนรูปไม่ตรงกับค่าที่กรอกหรือหน่วยที่เลือก
- รูปใหม่ทำให้ layout เดิมพังหรือ SVG เดิมเปลี่ยน

## ทางเลือก

| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| **A. แยก SVG ต่อโหมด (เลือก)** | แต่ละรูปตรงวงจรจริง อ่านง่าย แยกขาดจากกัน | มี markup ซ้ำใน template |
| B. SVG เดียวซ่อน/โชว์ชิ้นส่วน | ไม่ซ้ำ | geometry มีเงื่อนไข อ่านและแก้ยาก |
| C. คงข้อความ | แก้ศูนย์ | ผู้ใช้ไม่เห็นวงจร (ถูกปฏิเสธแล้ว) |

## การตัดสินใจ

- `templates/index.html`: คง SVG divider เดิมไว้ทุกบรรทัด เพิ่มอีกสองบล็อก
  เลือกด้วย `{% if mode == 'divider' %} / {% elif mode == 'fixed' %} / {% else %}`
- Fixed: RB จากราง VCC ลงเบส (ไม่มี R2), RC ลงคอลเลกเตอร์, อีมิตเตอร์ต่อกราวด์ตรง
- Emitter: RB จากราง VCC ลงเบส (ไม่มี R2), RC ลงคอลเลกเตอร์, RE จากอีมิตเตอร์ลงกราวด์
- `app.py`: `schematic_labels()` วนจากคีย์ของ `values` (จึงรองรับ `rb`) และ
  `render_page()` ส่ง `schematic` ให้ทุกโหมด
- ลบ `.schematic-note` และ CSS ที่ไม่ใช้แล้ว
- ค่าบนรูปมาจากค่าที่กรอกพร้อมหน่วย เหมือน divider; ค่าที่หายไปแสดง `—`
